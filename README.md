## 🔬 Key Engineering Features

1. **Semiconductor & Silicon HUD**:
   - Interactive 2D canvas visualizer simulating an active BGA/QFP silicon die, micro-blocks, copper traces, and pulsing electrons with zero heavy 3D bloat.
   - High-definition, authentic portrait and TCE collegiate seal extracted directly from verified credentials.

2. **The 9-Layer Signal Flow Spectrum**:
   - An interactive continuum mapping the flow of signals through physical and digital abstractions:
     `Transistor → Semiconductor → Digital Logic → FPGA → Embedded Systems → IoT → Networking → Edge AI → Applications`.
   - Real-time oscilloscope waveform monitor matching active layer signals (from drift-diffusion curves to RF chirp ramps and quantized AI activations).

3. **LoRa-Enabled Smart Bus Shelter Case Study**:
   - Complete 5-stage case study:
     - `01 — Problem`: Commuter arrival uncertainty and rural network voids
     - `02 — Concept`: Autonomous LoRa + GPS peer-to-peer telemetry
     - `03 — Detection`: Embedded real-time Haversine distance engine
     - `04 — Feedback`: Dual multi-lingual voice alerts and daylight-readable screen matrix
     - `05 — Connectivity`: Cellular-independent primary link with auxiliary internet sync
   - Interactive live distance simulation and schematic node inspector.

4. **Skill Topology & Constellation**:
   - Filterable skills matrix across Programming (C, C++, Python, Java), App Dev (Flutter), Semiconductor TCAD (Synopsys Sentaurus), and Engineering Interests (FPGA, Linux, Edge AI, IoT, Digital Design).
   - Dynamic node relations displaying interconnected hardware and software domains.

5. **Beyond the Circuit (Leadership)**:
   - Placement Representative (Department of ECE, TCE)
   - Joint Secretary (ECE Association, TCE)

6. **Interactive Easter Egg Terminal**:
   - High-tech CLI simulation accessible via the navbar `[TERMINAL ~]` button.

## 🛠️ Stack & Architecture

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Semiconductor Themes
- **Icons**: Lucide Icons + Custom SVG Brand Badges
- **Graphics**: High-DPI HTML5 Canvas (60 FPS, battery & mobile optimized)
- **Deployment**: GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)
- **Relative Asset Architecture**: Configured with `base: './'` for zero-config hosting at root or subpaths.
